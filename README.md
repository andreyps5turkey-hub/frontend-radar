# Frontend Radar

Ежедневная русскоязычная подборка по React и фронтенду. Сайт проверяет официальные
RSS/Atom-ленты и релизы, поднимает безопасность и ломающие изменения наверх,
сохраняет предыдущие выпуски и публикуется через GitHub Pages.

## Что есть в проекте

- актуальный выпуск в `data/digest.json`;
- архив выпусков в `data/archive/`;
- автоматически ранжированная подборка за последние семь дней на `/weekly/`;
- сравнение текущей недели с предыдущей без выдуманных процентов при нехватке данных;
- поиск и отдельные страницы каждого архивного выпуска;
- локальный профиль проекта на `/project/` с импортом `package.json`;
- сопоставление пакетов и semver-диапазонов с затронутыми версиями;
- версионный радар с major/minor/patch/security-сигналами и черновиком команд для pnpm, npm, Yarn или Bun;
- умная очередь обновлений со статусами и экспортом Markdown-чек-листа;
- локальные отметки «прочитано», «сохранено» и пресеты любимых тем;
- персональная очередь чтения с быстрыми переходами к сохранённым и непрочитанным;
- RSS-лента русских конспектов по адресу `/feed.xml`;
- состояние проверенных и временно недоступных источников;
- единый реестр из 32 крупных официальных и редакционных источников;
- приоритеты P0–P3;
- русские конспекты без полной перепечатки статей;
- ежедневный GitHub Actions workflow в 05:00 UTC (08:00 МСК);
- автоматическая публикация на GitHub Pages.

## Локальный запуск

Нужен Node.js `>=22.13.0` и pnpm `11.19.0`.

```bash
pnpm install
pnpm run dev
```

Проверка проекта:

```bash
pnpm run digest:validate
pnpm run lint
pnpm run test
```

`package.json` читается File API только в браузере. Профиль хранится в
`frontend-radar:project:v2`, а очередь действий — в
`frontend-radar:action-state:v1`. Эти данные не отправляются в GitHub, Groq или
другие сервисы.

## Ежедневное обновление

Workflow `.github/workflows/pages.yml` запускается по расписанию и вручную. Он:

1. собирает кандидатов из RSS, Atom, GitHub Releases и security advisories;
2. создаёт короткий русский выпуск через Groq `openai/gpt-oss-20b`;
3. проверяет ссылки статей и останавливает публикацию при подтверждённой `404` или `410`;
4. проверяет формат, сохраняет архив и обновляет поисковый каталог;
5. собирает главную, недельный обзор, локальную страницу проекта, архив, RSS и 404;
6. тестирует и публикует результат на GitHub Pages, затем коммитит новый выпуск.

Для редакторского шага нужен один GitHub Actions secret с именем `GROQ` и API-ключом
Groq. Ключ используется только как `GROQ_API_KEY` внутри шага генерации и не
попадает в репозиторий. При временной недоступности API скрипт создаёт выпуск в
детерминированном резервном режиме, поэтому публикация не останавливается.

## Источники

Базовый радар следит за React, Next.js, TypeScript, Vite, React Router, Redux
Toolkit, TanStack Query, Storybook, ESLint, Prettier, MDN, web.dev, TC39 и
крупными frontend-дайджестами. Для стека Reactor добавлены только значимые
первоисточники: Node.js, DOMPurify, core-js, Vite React Plugins, SWC,
typescript-eslint, Stylelint, Jest, React Testing Library, Puppeteer и Yarn Berry.

Полный машинно-читаемый список хранится в `data/sources.json`; его одновременно
используют ежедневный сборщик и карта источников на главной странице.
